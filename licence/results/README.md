# Licence rehearsal results

**Current gate statuses: `summary_current.json`.** Read this file and no other summary for a status.

- It is generated by the current code: `python3 summarize.py results --current results/summary_current.json` (run from `licence/`).
- `tests/test_evidence.py` (`test_f19_current_summary_artefact_is_what_the_code_produces`) fails if the file differs from what the code produces.
- For every life and every gate in its scope, it gives an explicit `status` (`PASS`, `FAIL` or `UNVERIFIED`) and a `reason`.
- `raw_checks` records, per life, why a figure taken from a raw file was not accepted.
- `aggregate` gives one status per gate: PASS only when every life passes, FAIL when any life fails, otherwise UNVERIFIED.

## How statuses are derived (review 9)

- **Raw rows are typed first** (`observe.parse_poll`, `observe.parse_work`).
  - Times must be finite epoch times inside the run window and in recording order, with no duplicates or overlaps.
  - Labels and HTTP statuses must agree, and arms and fields must stay in their closed domains.
  - The EXP1-T2 moments and the EXP2-T2, T3 and T5 figures are re-derived from the typed raw files at load.
  - A stored figure is used only if the raw files reproduce it. If there is no raw file, the file does not parse, or it disagrees, the gate is UNVERIFIED.
- **EXP1-T3** passes only when the adapter's own `ElasticsearchSearch._is_licence_error` recognises the message the adapter would build: `HTTP <code>: ` followed by the first 400 bytes of the body.
  - The committed lives recorded only an error summary, not that message, so EXP1-T3 is UNVERIFIED for them.

## Historical files

`SUPERSEDED.json` lists every superseded summary with its sha256:

- `summary_corrected.json`
- `summary_campaign.json`
- `summary_supp.json`
- `summary_down_7.json`

These files are kept **byte-identical** for provenance. Their sha256 values are in `SUPERSEDED.json` and `MANIFEST.sha256`, and a test checks both. None of them is a current status.

The recorded lives (`down_*.json`, `up_*.json`, `*.rows.gz`, `*.poll.gz`, `*.oracle.gz`) are also unchanged. Nothing was rerun.
